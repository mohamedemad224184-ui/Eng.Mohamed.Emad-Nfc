# Mohamed Emad — NFC Profile Card

ارفع الملفات إلى GitHub ثم فعّل **GitHub Pages**. اكتب رابط الصفحة المنشورة على كارت الـNFC فقط.

## تعديل سريع

- لتبديل الصورة، استبدل `images/profile.jpg` بصورة جديدة مع الاحتفاظ بالاسم نفسه.
- حدّث رابط فيسبوك من متغير `FACEBOOK_URL` في `script.js`.
- يكوّن QR تلقائياً من الرابط الفعلي الذي تُفتح منه الصفحة.
